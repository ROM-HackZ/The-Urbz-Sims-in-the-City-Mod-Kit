# more-furniture

New furniture for the Catalog (Furniture page) and the furniture shop (shop list 4).
For now each piece is a copy of an existing one (same look and use, new name and price):

| number | name | copy of |
|---|---|---|
| 430 | Farmhouse Armchair | Country Class Chair (136) |
| 431 | Bunkhouse Bed | Spartan Special Bed (131) |
| 432 | Lazy Sunday Recliner | Comfy Recliner (139) |

Add your own in `objects.json` (see the main README, "New objects and pets"). This mod uses the
numbers **430-511**; the `pets` mod uses 386 and 389-429, so the two can be built together.
No in-game switch: pick it in the mod manager before building.
